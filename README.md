# Reading and Writing Excel Data

Day - VEDA Technology Data Science Internship

This project demonstrates how to read, inspect, clean, transform, and write Excel data using Python and Pandas.

## Tasks Completed

- Created and read an Excel file using Pandas.
- Inspected rows, columns, data types, and summary statistics.
- Checked for missing values.
- Cleaned text columns and standardized department names.
- Calculated updated salaries and classified salary categories.
- Exported the processed data to a new Excel file.

## Tools Used

- Python
- Pandas
- OpenPyXL
- Jupyter Notebook
